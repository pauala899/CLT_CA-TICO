# Dias de produção

Cada dia de produção ganha uma pasta com a data no formato `AAAA-MM-DD`, seguindo a seção 10 do `CLAUDE.md`:

```
dias/AAAA-MM-DD/
├── 01-roteiro/
├── 02-referencias/
├── 03-artes/
│   ├── feed/
│   ├── stories/
│   ├── reels/
│   └── carrossel/
├── 04-legendas/
└── 05-aprovados/
```

Separar claramente:

- Originais gerados.
- Arquivos em edição.
- Versões revisadas.
- Versões aprovadas.

Não sobrescrever arquivos aprovados sem autorização.

O status de cada peça fica em `registro-aprovacao.md`.
